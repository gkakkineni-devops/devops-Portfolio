# DevOps Portfolio

Personal DevOps portfolio project built as a practical learning project.

## Current Progress

- HTML structure completed
- Responsive CSS design completed
- JavaScript interactions completed
- Git version control configured
- GitHub remote repository configured
- Portfolio deployed with GitHub Pages
- GitHub Actions CI workflow configured

## Version Control

This project uses Git for local version control and GitHub as the remote repository.

## CI/CD

The project uses GitHub Actions to:

- Validate required source files
- Check basic HTML references
- Detect committed local environment files
- Build the Docker image
- Start the portfolio container
- Verify the Nginx-served website
- Test HTML, CSS, and JavaScript endpoints
